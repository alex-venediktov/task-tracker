# Приложение, смонтированное в FastAPI на "/", перехватывает все пути, объявленные после него

**тип:** порядок · **предмет:** маршруты рядом с MCP · **этапы:** plan, implement

**вывод:** Starlette сверяет маршруты и монтирования по порядку объявления, а `app.mount("/", ...)`
совпадает с любым путём. Маршрут или `app.mount("/static", ...)`, объявленный после монтирования на
корень, недостижим: запрос уходит в смонтированное приложение (здесь - MCP) и получает его ответ.
Собственные страницы, статика и REST объявляются до `app.mount("/", mcp_app)`. Ловится тестом, что `/`
отдаёт страницу, а неизвестный файл статики - 404 статики.
