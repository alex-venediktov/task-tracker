# Контейнер без TZ пишет время задач в UTC: метки расходятся с часами владельца

**тип:** ограничение · **предмет:** время в контейнере · **этапы:** plan, implement

**вывод:** контейнер без `TZ` живёт в UTC или наследует пояс хоста. Служба ставит метки задач через
`datetime.now()` без пояса, поэтому без `TZ` задача, созданная в 21:49 по часам владельца (UTC+4),
получает `17:49`. Тесты и запуск из исходников на рабочей станции этого не видят: там часы уже местные.
Пояс задаётся контейнеру переменной `TZ`; база поясов в образе `python:3.12-slim` есть. Проверка -
`docker exec <контейнер> date`.

**источник:**
- `tracker/store.py:34` - `return datetime.now().strftime("%Y-%m-%dT%H:%M")`
