# Настройки проекта для «Волны»

> Файл коммитится — это общая для команды часть настроек: команды и конвенции, без секретов и
> без машинных путей. Всё приватное берётся из `.env` и здесь упоминается только именем
> переменной. Проверить — `/volna:doctor`.

## Профиль

Этапы читают эти строки первым делом и **не делают того, чего в проекте нет**. Имена ключей и
значений менять нельзя: по ним профиль читают этапы и hooks (`readProfile`).

- репозитории: один
- трекер: нет
- приём задач: текст
- доставка: commit+push
- закрытие: журнал
- эталон: нет

Что это значит: работа идёт в этом репозитории (`repos[]` журнала пуст); все задачи локальные
(`mode: local`) и ставятся текстом или файлом, число читается как локальный id; `deliver` —
коммит и push в `origin`, PR не создаётся; `close` идёт ветвью Г — часы и итог в журнал; сверки с эталоном
и правил порта нет.

## База знаний

MCP-сервер поиска — `KB_MCP_NAME`. Не настроен → поиск идёт `Grep`/`Glob`, это отмечается в
журнале.

## Команды

| Зачем | Команда |
|---|---|
| окружение | `python -m venv .venv` и `.venv/Scripts/python -m pip install -e ".[dev]"` |
| сборка | `docker build -t task-tracker .` |
| юнит-тесты | `.venv/Scripts/python -m pytest -q` |
| линт | `.venv/Scripts/python -m ruff check .` |
| дымовой запуск | `TT_DATA_DIR=<каталог> TT_GIT=0 .venv/Scripts/tracker` - порт 8113 |

Строка «чего не запускать» не заведена — ограничений на прогоны нет. Появятся тесты с внешними
последствиями (живая БД, стенд, миграции) — добавить строку с командой, причиной и заменой.

## Конвенции

- ветка: `bugfix/<id>-<slug>` для bug, `feature/<id>-<slug>` для story/task; точка отвода
  новых веток — `TARGET_BRANCH`;
- коммит: одна строка `<id> <что сделано>`; `git add -A` перед коммитом; **без** трейлеров
  (в том числе без `Co-Authored-By`);
- комментарии: одна строка «что делает (`<источник>`)», русский язык,
  ASCII-пунктуация (`->`, `-`, `"`), без номеров задач;
- тесты: PascalCase `Method_State_Expected`, обязательный doc-комментарий;
- фикстуры: оффлайн-снимок данных в JSON, без обращения к живой БД.

## Локальное (не коммитить)

Машинно-зависимое — в `.env`; персональное — в `.volna/project.local.md` (уже в `.gitignore`).
